## Veröffentlichung

Euer bestehender GitHub-Pages-Link bleibt unverändert:
https://studentdhbw.github.io/DHBW-monitorhalter/

Wichtig: Beim Upload müssen `index.html`, `style.css`, `script.js`,
`assets` und `downloads` DIREKT im Hauptverzeichnis des Repositories liegen.
Nicht den übergeordneten Ordner `mount-ing-website-final` hochladen.

eurer Projektdokumentation basieren, die Website aber bei Gestaltung und

offiziellen GitHub-Pages-Anleitung veröffentlicht wurde.
